# Cownter branding

- `cownter-logo.png`: transparent project logo with the wordmark.
- `cownter-symbol.png`: transparent square symbol, the source for app and tray icons.
- `../icons/`: PNG sizes, Windows ICO, macOS ICNS and monochrome tray icons.

Regenerate the platform icon sizes with `python3 scripts/build_icons.py` from the
project root (needs Pillow).
